📖 Paano Gamitin ang RAIN-Tag Alcala

Tagalog na gabay para sa mga magsasaka — basahin bago mag-submit.

  1. Ilagay ang inyong pangalan. Sa Hakbang 1, i-type ang inyong First Name, Middle Name, at Last Name. Pindutin ang “Susunod”.
  2. I-on ang Location Services ng cellphone. Sa Settings ng inyong cellphone, buksan ang Location / GPS, at i-allow ang app/browser na gamitin ang lokasyon. Sa camera settings, i-on din ang “Location tags / Geo-tagging” upang maisulat ng larawan ang GPS nito (EXIF geotag).
  3. Kunin ang live na lokasyon. Sa Hakbang 2-A, pindutin ang “Kunin ang Lokasyon (Get Location)” at pahintulutan ang hiling ng browser. Mas mainam kung nasa open area / labas ng bahay kayo para malinaw ang GPS signal.
  4. Kunan ng larawan ang rice area. Sa Hakbang 2-B, pindutin ang “Kunan ng Larawan”. Gumamit ng malinaw at buong kuha ng palayan. Tiyaking naka-on ang GPS bago kumuha upang may geotag ang litrato.
  5. Strict ang app sa GPS. Tatanggapin lamang ang larawan kung may EXIF GPS (geotag) ito O kaya may nakuha kayong live na GPS bago mag-take ng larawan. Kung wala ang dalawa, hindi ito tatanggapin.
  6. I-submit. Kapag berde ang status ng GPS at larawan, pindutin ang “I-submit ang Datos”. Hintayin ang kumpirmasyon.
  7. Ang admin lamang ang makakakita ng database. Sinuman ay maaaring mag-submit ng datos, ngunit tanging ang admin ng Rainfed Inventory ang makakakita ng mapa (Leaflet) at mga naitalang lugar, at siya lang ang makaka-export ng CSV at GeoJSON.
Paalala: Ang mga pekeng larawan o larawang walang GPS ay awtomatikong tinatanggihan ng sistema. Siguraduhing totoo at may geotag ang inyong isinusumite.

Bakit kailangan ang GPS?

Ang GPS coordinates ang nagtatakda ng eksaktong lokasyon ng inyong rainfed rice area sa mapa ng Alcala. Ito ang gagamitin ng pamahalaan para sa tamang inventory at pagpaplano ng suporta sa mga magsasaka.
