📖 Paano Gamitin (Offline App)

  1. Ilagay ang pangalan at tirahan → Susunod.
  2. I-on ang Location/GPS ng cellphone para sa geotag at compass.
  3. Buksan ang Camera — camera ng app lamang, bawal ang upload.
  4. Pindutin ang KUNAN — kinukuha ang GPS at direksyon (compass) bago kumuha.
  5. Itala sa Cellphone — nai-save lahat offline sa inyong device.
  6. Admin / Datos — pindutin ang tab sa itaas (PIN: 1234) upang makita ang mapa, table, at i-export ang CSV / GeoJSON / mga larawan (ZIP).
Paalala: para sa tunay na larawan, i-on ang Location Services. Walang internet? Walang problema — ang mapa lamang ang kailangan ng signal; ang datos ay kumpletong offline.
